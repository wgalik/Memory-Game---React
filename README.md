# 🧠 Memory Game – React

A multi-level memory card game built with React and Webpack. Test your memory skills by flipping cards, advancing through difficulty levels, and tracking your score. Clean transitions and state management make for a smooth and interactive experience.

🔗 [Play the game live](https://wgalik.github.io/Memory-Game---React/)

---

## 🚀 Features

- 🔁 Multiple levels with increasing difficulty
- 🎴 Flip cards to find matching pairs
- 🧮 Score tracking and game completion summary
- 🧭 Navigation between levels using React Router
- 💾 Global state management using React Context API + custom store
- 🎬 Smooth page and component transitions using React Transition Group
- ⚙️ Built-in difficulty settings with varied board layouts

---

## 🛠️ Technologies

- **React**
- **JavaScript (ES6+)**
- **SCSS**
- **React Router**
- **React Context API**
- **React Transition Group**
- **Webpack**

---

## 🧪 Development Notes

- Modular, reusable React components
- Custom global state store via Context API
- SCSS modules for styling and responsiveness
- Transitions handled with SwitchTransition and CSSTransition
- Built using custom Webpack configuration
